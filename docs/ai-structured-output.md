# AIを機能として載せる（第63課題・構造化出力／ツール利用）

作成日: 2026-10-12。実装: `api/suggest-product.js` / `api/_lib/suggestProduct.js` / `src/lib/productSuggest.js` / `src/components/RegisterPanel.jsx`。
**状態: 実装済み・Claude APIで動作確認済み・テスト33件パス。ただし本番(Railway)では動かない（理由は下記）。**

## ① 載せどころ

「入力 → AI → 決まった形の出力」の1本道になる所を探した。

| 候補 | 形 | 判断 |
|---|---|---|
| **商品登録: 商品名の整形＋カテゴリ提案** | 構造化出力 `{name, category}` | **採用**。Yahoo!から取れる商品名は「【送料無料】…まとめ買い あす楽」のように長くて雑。毎回手で直している作業で、答えが1つの形に決まる |
| チャットで「在庫を調べて」と頼む | ツール利用（`listStock` を呼ばせる） | 見送り。チャットは `CHAT_ENABLED=false`（Railwayに `/api` がない）で、先にEdge Functionsへの移行（第56課題）が要る |
| 自然文での在庫操作（「牛乳を3つ出庫」） | ツール利用（`adjustQuantity` を呼ばせる） | 見送り。書き込みをAIに任せるのは、承認画面など守りの設計が先に要る |

## ② 実装したもの

```
バーコードをスキャン（未登録）
  → Yahoo!で商品名を取得（長くて雑な名前）
  → フォームを先に表示（待たせない）
  → 裏で /api/suggest-product に { rawName, 既存カテゴリ } を送る
       ログイン確認 → 回数制限(10分に30回) → 入力検証 → Claude(Haiku 4.5)
  → 決まった形 { name, category } が返る → 検証して、フォームの欄に埋める
  → 「AIが整えました。確認して直してください」と出す → 保存はユーザーが押したときだけ
```

**構造化出力の作り方**: `register_product_fields` というツールを定義し、`tool_choice` でそのツールを**必ず呼ばせる**。
ツールの入力の形（JSON Schema: `name` と `category` は必須の文字列）が、そのまま出力の形になる。
文章で返す余地がないので、アプリは正規表現などで答えを探さずに、そのまま受け取れる。

## ③ 使いどころと、気をつける点（間違った出力への備え）

**効く所**: 答えが「決まった形」で、人が確認してから使う作業。AIは下書きを作り、人が確定する。
今回は、手で直していた商品名の整形とカテゴリ選びがこれに当たる。

**気をつける点と、入れた備え**

| 危険 | 備え |
|---|---|
| AIが形の違う答えを返す | ツールの呼び出しを強制し、受け取ったあとに**サーバーで検証**する（型・空・長さ）。ダメなら捨てる（`parseSuggestion`、テストあり） |
| AIが間違える・情報を落とす（実際にメーカー名が消えた） | **自動で保存しない**。欄に入れて「AIが整えました」と出し、ユーザーが確認・修正して登録する |
| 外部サイトの商品名に、AIへの命令が混ざる | 商品名は `<raw_name>` で囲み「ただのデータ」と指示。AIに**書き込みの権限を渡さない**（出力は表示用の2つの文字列だけ） |
| 費用・悪用 | ログイン必須、10分に30回まで、入力は200文字・カテゴリ50件まで、`max_tokens: 200`、安いモデル（Haiku 4.5） |
| 遅い・落ちる | 5秒でタイムアウト。失敗しても**今までどおり手入力で進める**（AIは補助） |
| 入力済みの欄を上書きする | 名前が変わっていなければ入れ替え、カテゴリが空のときだけ入れる。次の商品に古い提案が入らないよう、リクエスト番号で捨てる |

## 注意：本番（Railway）ではまだ動かない
本番は静的配信（nginx）で、`/api/` を実行するサーバーがない（チャットが無効なのと同じ理由）。
本番の画面では、AIの呼び出しが失敗して**今までどおり**の登録画面になる（壊れない）。
動くのは `/api` が使える環境（Vercelのプレビュー）まで。本番で使うには、第56課題の計画どおり
**Supabase Edge Functions へ移す**（`suggestProduct.js` は、Anthropicのクライアントを引数で受ける作りなので、そのまま持っていける）。
