# お金の実務: 請求・入金・経費・税(第85課題・想定案件)

> **これは練習用の想定案件です。** 依頼者・金額・日付・登録番号はすべて例で、実在の取引ではありません。
> 税の内容は一般的な仕組みの説明で、制度や数字は変わります。**実際の申告・インボイス登録・源泉徴収の判断は、税務署の案内か税理士に確認してください。** 私(Claude)の説明は専門家の確認を受けていません。
> 案件は第82・84課題と同じ(小さな店の在庫管理アプリ導入、一式 約28万円・税別、着手時50%/検収後50%)。

## ① 請求書テンプレと、1枚埋めた例

### 請求書に書くこと(項目)

| 項目 | 書くこと | 注意 |
|---|---|---|
| 書類名・番号 | 「請求書」、請求書番号(連番) | 番号は連番にして、後から探せるようにする |
| 請求日 | 発行する日 | |
| 宛名 | 依頼者の正式名称(店名・屋号・会社名) | 敬称は「御中」(会社・店)か「様」(個人) |
| 発行者 | 自分の名前(屋号)・住所・連絡先 | |
| 登録番号 | インボイス登録をしている場合は `T`+13桁 | 課税事業者として登録した場合のみ |
| 件名 | 何の請求か(案件名と、何回目の請求か) | |
| 明細 | 内容・数量・単価・金額 | 税抜金額と消費税を分けて書く |
| 合計 | 税込の請求金額 | |
| 支払期限 | 日付で書く(「検収後14日以内」でなく実際の日付) | 契約の支払い条件と合わせる |
| 振込先 | 銀行・支店・口座種別・番号・名義 | |
| 備考 | 振込手数料の負担、外部サービス料は含まないこと | 「手数料はご負担ください」と先に書く |

## ② お金の流れと、記録しておくこと

```
受注(契約) → 着手時に請求 → 入金確認 → 納品・検収 → 残りを請求 → 入金確認 → 記録・保管
```

| 段階 | やること | 記録しておくこと |
|---|---|---|
| 受注 | 契約(メール合意でも可)・見積書を保存 | 契約書、見積書、仕様書 |
| 請求 | 請求書を発行して送る(PDFとメール本文) | 請求書の控え、送った日 |
| 入金確認 | 口座に振り込まれたか確認する。**期限の翌日に見る** | 入金日、入金額(手数料が引かれた額も) |
| 未入金 | 期限を過ぎたら、すぐ丁寧に連絡する | 連絡した日と内容 |
| 経費 | 仕事に使ったお金をその都度記録 | 日付・金額・何に使ったか・領収書(またはデータ) |
| 保管 | 書類を整理して残す | 請求書・領収書・通帳の写し |

**経費になりうるもの(例):** パソコンやスマホ実機の購入(高額なものは減価償却の対象)、ホスティングやドメイン代、ソフトのサブスク、通信費・電気代の仕事分(家事按分)、書籍、打合せの交通費。

**注意:** 私用と仕事の支出が混ざるものは、仕事の割合を決めて(按分)記録する。私用の分は経費にしない。仕事用の口座を分けると、記録がずっと楽になる。

**この案件で言えること:** 契約で「外部サービスの費用は依頼者の名義で契約する」と決めたので、Supabase等の費用は自分の経費にならず、依頼者の負担になる(第82課題)。ただ、開発中に自分の名義で払った分があれば、清算の仕方を先に決めておく。

## ③ 個人事業の税の基礎(初心者向け・ざっくり)

| 項目 | 内容 |
|---|---|
| 確定申告とは | 1年間(1月〜12月)の**売上 − 経費 = 所得**を計算して、税額を自分で申告・納付する手続き。翌年の2月中旬〜3月中旬が申告の期間 |
| 開業届 | 事業を始めたら、税務署に開業届を出す。あわせて**青色申告承認申請書**を出すと、青色申告ができる |
| 青色申告 | 帳簿をきちんとつけると、**最大65万円の控除**(条件あり。電子申告など)が受けられる。白色より得になることが多い |
| 所得税 | 所得が増えるほど税率が上がる。住民税・国民健康保険料も所得に連動して増える |
| 消費税 | 課税売上が一定額(1,000万円)以下なら、原則として免税事業者。ただし、依頼者から「インボイス登録をしてほしい」と言われることがある |
| インボイス制度 | 依頼者が消費税の控除を受けるには、請求書に登録番号が必要。登録すると課税事業者になり、消費税の申告が必要になる。登録するかは、依頼者との関係と負担を見て決める |
| 源泉徴収 | 報酬の種類によっては、依頼者が税金を引いて払うことがある。引かれた分は、確定申告で精算する。**システム開発が対象かは、報酬の内容で変わるので要確認** |

### 日頃やっておくこと

1. 売上・経費を**毎月**、帳簿(会計ソフトや表)につける。年末にまとめてやらない
2. 請求書・領収書・通帳の写しを捨てずに保管する(保存期間は書類で異なる。数年〜7年)
3. 仕事用の口座とカードを分ける
4. **税金を払う分を先に取り分ける**(例: 売上から毎回2〜3割を別口座へ。割合は所得で変わる)
5. 開業届・青色申告承認申請書を出しておく(期限あり。早めに調べる)
