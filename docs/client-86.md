# クライアント対応と自己管理(第86課題・想定案件)

> **これは練習用の想定案件です。** 依頼者・日付・数字はすべて例で、実在の取引ではありません。
> 案件は第82・84・85課題と同じ(小さな店の在庫管理アプリ導入、期間4週間、約28万円)。文面は私(Claude)の案で、実際の依頼者に使ったことはありません。

## ① 報連相の型(進捗報告テンプレ)

### 頻度の決め方

| 種類 | 頻度 | 理由 |
|---|---|---|
| 定例の進捗報告 | **週1回、曜日を固定**(例: 毎週金曜の夕方) | 「いつ来るか」が分かるだけで、相手は待てる |
| 確認の依頼(返事がほしいもの) | 気づいたその日 | 返事待ちの日数は、契約上、納期に足せる(第82課題) |
| 悪い知らせ(遅れ・問題) | **分かった時点ですぐ** | 当日連絡は最悪。早いほど対策の選択肢が残る |
| 納品・検収 | 完成の連絡と、確認してほしいことを1通で | 7日以内の検収期限を、日付で書く |

### テンプレ(メール・チャット共通)

```
件名: 【進捗報告】在庫管理アプリ 第〇週(〇月〇日)

〇〇様
お世話になっております。山田(例)です。今週の進捗をご報告します。

■ 全体の状況: 順調 / 注意 / 遅れあり  (いずれか1つ)
   進み具合: 全体の約〇%(作業 〇/10 完了)

■ 今週やったこと
・〇〇(完了)
・〇〇(完了)

■ 来週やること
・〇〇

■ ご確認・ご判断いただきたいこと(期限: 〇月〇日)
・〇〇について、A案とB案のどちらにしますか(私のおすすめはA。理由は〇〇)
 (なければ「特にありません」と書く)

■ 気になっている点・リスク
・〇〇(対応: 〇〇)
 (なければ「特にありません」と書く)

■ 納期の見通し: 〇月〇日の予定どおり / 〇日ずれる見込み

以上です。ご不明な点があれば、お気軽にご連絡ください。
```

**書き方のコツ**
- 最初の1行で「順調か、注意か、遅れか」が分かるようにする(読まなくても安心できる)
- 「ご確認いただきたいこと」は、**選べる形**で書く。「どうしますか?」だけにしない
- 悪い話は、**原因・影響・対策**の3点セットで書く(後述)
- 「特にありません」も書く。空欄だと、書き忘れか問題なしか分からない

## ② 気まずい連絡の言い方

### 「遅れそうです」

> 〇〇様、お世話になっております。
> 先にお伝えしたいことがあり、ご連絡しました。**〇〇機能の完成が、予定の〇月〇日から〇月〇日へ、3日ほど遅れる見込みです。**
> 原因は、お店のスタッフ様のスマホ(〇〇機種)で、バーコードの読み取りが安定しなかったためです。実機で調整する時間が、想定より必要でした。
> 他の作業は予定どおりで、**検収と全体の納期への影響は、今のところ〇日以内**に収まる見込みです。
> 対策として、〇〇を先に進め、〇月〇日にもう一度、見通しをご連絡します。
> 何かご懸念やご希望があれば、お知らせください。

**型:** ①最初に結論(何がどれだけ遅れるか)→ ②原因(言い訳でなく事実)→ ③影響の範囲 → ④対策と次の連絡日 → ⑤相手の希望を聞く。**謝罪より、情報と見通しを先に出す。** 迷惑をかけたなら、最初か最後に一言だけ添える。

### 「それは範囲外です」

> 〇〇様、ご要望ありがとうございます。**ぜひ形にしたいです。**
> ご相談の「入出庫の履歴を画面で見られるようにする」は、今回の契約の範囲(別紙のスコープ表)には入っていないため、**追加のご相談**となります。
> 見積りを出しますので、**内容・金額・納期**を確認いただき、ご納得いただいてから着手します。目安は〇時間で、〇万円(税別)です。今回の納期には影響しないよう、別枠で進める形にします。
> 「今回は見送って、あとで改めて」でも大丈夫です。ご希望をお聞かせください。

**型:** ①まず前向きに受け止める → ②範囲外であることを、**契約・スコープ表という「事実」で**伝える(「やりたくない」でなく「枠が違う」) → ③次の道を示す(見積り/見送り) → ④選ぶのは相手。**「できません」でなく「別枠でできます」と言う。**

### 避けたい言い方と、言い換え

| 避けたい | 言い換え(例) |
|---|---|
| 「それは聞いていません」 | 「その点は仕様書に入っていなかったので、確認させてください」 |
| 「無理です」 | 「今回の範囲では難しいです。別の形なら〇〇できます」 |
| 「頑張ります(根拠なし)」 | 「〇日までにお出しできます。理由は〇〇です」 |
| 当日の「すみません、遅れます」 | 分かった時点で、日数と対策を付けて連絡 |
| 返事がない相手に何も言わない | 「〇日までにご回答がない場合、納期が〇日延びます」と、期限と影響を添えて再送 |

## ③ 自分を守る自己管理ルール3つ

| # | ルール | やり方(例) |
|---|---|---|
| 1 | **その場で「はい」と言わない** | 依頼・追加要望・納期の約束は「確認して〇時までに返事します」と一度持ち帰る。見積り(第84課題)を出してから答える |
| 2 | **同時に抱える量に、上限を決める** | 並行して受ける案件は〇件まで。1週間の仕事に入れる時間は、見積りの「請求できる時間(月100時間)」を超えない。上限なら断るか、待ってもらう |
| 3 | **バッファと休みを、先に予定へ入れる** | 見積りの30%バッファは、納期にも使う。週に1日は、仕事をしない日にする。納期の2〜3日前を「自分の締切」にする |

**この3つの根拠(自分の仕組みとのつながり)**
- #1 は、第82課題の「範囲外は書面で合意してから着手」と、第84課題の「ちょっとだけ、でも口約束で受けない」と同じ考え
- #2 は、第84課題で単価を「月100時間」から逆算したことと対応する。上限を超えると、見積りの前提が崩れる
- #3 は、第84課題のバッファ30%と対応する。削ると、遅れの連絡が増える
