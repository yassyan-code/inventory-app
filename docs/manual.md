# 使い方マニュアル

在庫管理アプリの使い方を、初めて使う人向けに説明します。

対象URL: https://inventory-app-topaz-iota.vercel.app

---

## 1. ログインする

初回はアカウント作成が必要です。

1. アプリを開くと「ログイン」画面が表示されます
2. まだアカウントがない場合は「アカウントを作成する」を押す
3. メールアドレスとパスワード（6文字以上）を入力して「アカウント作成」を押す
4. 入力したメールアドレスに確認メールが届くので、メール内のリンクを開く
5. アプリに戻り、「ログインに戻る」からメールアドレスとパスワードでログイン

2回目以降は、メールアドレスとパスワードを入力して「ログイン」するだけです。

> 一度登録したアカウントは、他の端末（スマホ・PCなど）からログインしても同じデータを見られます。

---

## 2. 商品を登録する（スキャン登録タブ）

### スマホの場合（カメラで読み取る）

1. 上部タブから「スキャン登録」を選ぶ
2. 「📷 カメラで読み取る」を選ぶ（初回はカメラの使用許可が必要）
3. バーコードを画面の枠内に映すと自動で読み取られる

### PCの場合（バーコードスキャナーで読み取る）

1. 「🔌 スキャナーで読み取る」を選ぶ
2. USB/Bluetoothのバーコードスキャナーでバーコードを読み取る（キーボード入力と同じ扱いになります）

### カメラ・スキャナーが使えない場合

「うまく読み取れない場合はバーコード番号を直接入力」の欄に番号を手入力し、「この番号で確認する」を押します。

### 読み取った後の動き

- **すでに登録済みの商品**だった場合
  → 自動で在庫数が+1（入庫）されます。数量を修正したいときは「＋1（入庫）」「−1（出庫）」ボタンで調整してください。
- **初めて読み取る商品**だった場合
  → 「新しい商品です」という登録フォームが出ます。商品名（自動入力される場合あり）・カテゴリ（任意）・数量を入力して「登録する」を押してください。

> 商品名や数量を空欄のまま登録しようとすると、赤字でエラーメッセージが表示されます。メッセージに従って入力し直してください。

---

## 3. 在庫を確認・管理する（在庫一覧タブ）

1. 上部タブから「在庫一覧」を選ぶ
2. 登録済みの全商品が一覧表示される

できること:

| 操作 | 方法 |
|---|---|
| 商品を検索 | 上部の検索欄に商品名・バーコード・カテゴリの一部を入力（自動で絞り込み） |
| カテゴリで絞り込み | 「すべてのカテゴリ」のプルダウンから選択 |
| 並び替え | 「名前順」「新しい順」「古い順」ボタンで切り替え |
| 数量を増減 | 各行の「＋1」「−1」ボタン |
| カテゴリを変更 | カテゴリのセルをクリック→入力→Enterまたは他の場所をクリックで保存 |
| 商品を非表示にする | 「非表示」ボタン（確認ダイアログが出ます。データは消えず、後で復元できます） |
| 非表示の商品を戻す | 「非表示の商品も表示する」にチェック→対象商品の「復元」ボタン |
| 一覧をCSVで書き出す | 「CSVエクスポート」ボタン（今表示中の検索・絞り込み条件がそのまま反映されます） |

---

## 4. AIチャットに質問する（チャットタブ）

上部タブの「チャット」を開くと、アプリの使い方などをAIに質問できます。メッセージを入力して「送信」を押してください。

---

## 5. うまくいかないときは

| 症状 | 対処 |
|---|---|
| カメラが起動しない・映らない | スマホのブラウザ設定でカメラの使用を許可しているか確認してください。`http://`のIPアドレス経由（社内LANなど）ではカメラが動作しないことがあるため、本番URL（`https://`）からアクセスしてください |
| 赤字でエラーが出た | メッセージの内容（空欄・文字数オーバー・数量の入力ミスなど）に従って入力し直してください。落ちたり固まったりすることはありません |
| ログインできない | 確認メールのリンクを開いたか、パスワードが6文字以上かを確認してください |

不明点はチャットタブで質問するか、開発担当に確認してください。
