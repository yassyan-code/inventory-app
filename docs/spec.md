# 仕様書

在庫管理アプリの機能仕様。最終更新: 2026-08-20（関門⑨・納品パッケージ回）

> ヒアリング段階の要望（バーコードで商品と数量を登録・管理したい）をもとに実装した現在の完成版の仕様です。

## 1. 概要

- **アプリ名**: 在庫管理アプリ
- **目的**: バーコードをスキャンするだけで、商品の登録・在庫数の入出庫記録を行える
- **利用形態**: 複数人・複数端末でクラウド上のデータを共有（Supabaseアカウントでログインした人は全員同じ在庫データを見る）
- **本番URL**: https://inventory-app-topaz-iota.vercel.app
- **対応環境**: スマホ（PWA、カメラでバーコード読取）／PC（USB/Bluetoothバーコードスキャナー対応）

## 2. 機能一覧

### 2.1 認証
- メールアドレス＋パスワードでのアカウント作成・ログイン（Supabase Auth）
- 新規登録時はメール確認が必要
- ログイン状態はセッションとして保持され、ログアウトボタンで終了できる

### 2.2 商品スキャン・登録（スキャン登録タブ）
- スマホカメラでのバーコード読取（`@zxing/browser`、背面カメラ優先、EAN-13等の1Dバーコード）
- PC用: キーボードエミュレーション型バーコードスキャナーからの入力
- バーコード手動入力（読み取り不可時のフォールバック）
- 登録済みバーコードを読み取ると、自動で在庫+1（入庫記録も残る）
- 未登録バーコードの場合、新規登録フォームを表示
  - 商品名: Yahoo!ショッピング商品検索APIで自動取得を試み、取得できなければ手入力（未設定でも動作）
  - カテゴリ: 任意入力（既存カテゴリの入力補完あり）
  - 初期数量: 手入力
- 入力バリデーション（2026-08-20 追加）
  - 商品名: 必須、100文字以内
  - カテゴリ: 50文字以内
  - 数量: 0以上の整数、999,999以下
  - バーコード（手動入力）: 必須、50文字以内
  - 不正な入力時はエラーで落ちず、赤字メッセージで理由を表示
  - 登録ボタン・＋1/−1ボタンは処理中は無効化し、連打による二重処理を防止

### 2.3 在庫一覧・検索（在庫一覧タブ）
- 全商品の一覧表示（商品名・カテゴリ・バーコード・登録日・数量・状態）
- 商品名・バーコード・カテゴリでの部分一致検索（入力のたび自動、0.3秒デバウンス）
- カテゴリでの絞り込み（プルダウン）
- 並び替え: 名前順／新しい順／古い順
- 数量の手動調整（＋1／−1ボタン、各行に入出庫記録が残る）
- カテゴリのインライン編集（セルクリックで編集、Enter/フォーカス外れで保存、Escapeでキャンセル）
- 商品の非表示化（論理削除）・復元
  - 「非表示」ボタン押下時に確認ダイアログを表示
  - 非表示にしても在庫データ・入出庫履歴は保持される（物理削除しない）
  - 「非表示の商品も表示する」チェックボックスで非表示商品も一覧に表示可能。非表示商品には「復元」ボタンを表示
- CSVエクスポート
  - 現在表示中の一覧（検索・絞り込み・並び替え・非表示表示の状態を反映）をCSVでダウンロード
  - ファイル名: `inventory_YYYY-MM-DD.csv`
  - 列: 商品名・カテゴリ・バーコード・登録日・数量・状態
  - UTF-8 BOM付き（Excelでの文字化け対策）

### 2.4 AIチャット（チャットタブ）
- Claude APIを使ったチャット機能。アプリの使い方などを質問できる
- メッセージは2000文字以内（超過時は赤字メッセージ）
- APIキーはサーバー側（Vercel Functions）のみで使用し、ブラウザには渡らない

## 3. データモデル（Supabase / PostgreSQL）

### `products`（商品マスタ）
| 列 | 型 | 説明 |
|---|---|---|
| id | uuid (PK) | |
| barcode | text (unique, not null) | バーコード |
| name | text (not null) | 商品名 |
| category | text (nullable) | カテゴリ |
| archived_at | timestamptz (nullable) | 非表示にした日時（nullなら表示中） |
| created_by | uuid | 登録者（auth.users参照） |
| created_at / updated_at | timestamptz | |

### `stock_items`（在庫）
| 列 | 型 | 説明 |
|---|---|---|
| id | uuid (PK) | |
| product_id | uuid (unique, FK→products, cascade delete) | 商品1件につき1行 |
| quantity | integer (not null, default 0) | 現在の在庫数 |
| updated_at | timestamptz | |

### `stock_movements`（入出庫履歴）
| 列 | 型 | 説明 |
|---|---|---|
| id | uuid (PK) | |
| product_id | uuid (FK→products, cascade delete) | |
| change | integer (not null) | 正=入庫、負=出庫 |
| note | text | 「入庫」「出庫」「初期登録」など |
| created_by | uuid | |
| created_at | timestamptz | |

### 権限（RLS）
- 3テーブルともRLS有効。**ログイン済みユーザーなら誰でも読み書き可能**な簡易ポリシー（チームやユーザーごとのデータ分離はまだ行っていない）

## 4. 外部サービス連携

| サービス | 用途 |
|---|---|
| Supabase | 認証（Auth）、データベース（Postgres） |
| Vercel | ホスティング、`master`ブランチへのpushで自動本番デプロイ、PR/他ブランチはプレビューデプロイ |
| Yahoo!ショッピング商品検索API | 未登録バーコードの商品名自動取得（任意・未設定でも動作） |
| Anthropic Claude API | チャット機能の応答生成 |
