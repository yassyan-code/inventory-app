> 点検は、コードと配色の**数値計算**(WCAG の文字コントラスト比)で行いました。**実際のスクリーンリーダー(読み上げ)・キーボードだけの操作・拡大表示は、実機で確かめていません。** 合格の目安は、普通の文字で 4.5 以上(大きい文字は 3 以上)です。

## ② 直した内容

### 直した1つ目: 色のコントラスト(#1〜#4)

| 場所 | 直す前 | 直した後 |
|---|---|---|
| 暗い画面の青いボタンの白い文字 | 3.68 | **5.17**(塗りつぶし用の青 `--accent-strong` を分けた) |
| 「管理者」バッジの文字(明/暗) | 4.24 / 2.82 | **12.03 / 8.37**(文字色を本文色にした) |
| 非表示の行の補助の文字(明/暗) | 2.28 / 4.06 | **4.63 / 8.55**(半透明をやめて、補助色を使う) |
| 「選択中」の見分け方 | 色だけ | 色+**太字**+読み上げ用の属性(`aria-pressed` / `aria-current`) |

直さなかった理由: 暗い画面の青い**文字・リンク**(4.86)は、基準を満たしていたので、そのまま。ボタンの塗りだけを別の色にした。

### 直した2つ目: 読み上げへの対応(#5〜#8)

- `index.html` の言語を `ja` に(日本語の発音で読まれる)
- 検索欄・カテゴリ選択に名前を付けた(`aria-label`)
- ＋1/−1/非表示/復元に、商品名入りの名前を付けた(例: 「牛乳 の在庫を1個増やす」)
- カメラ映像に名前を付け、エラー表示を `role="alert"`(出たらすぐ読み上げ)にした

変更: `index.html`、`src/index.css`、`src/App.css`、`src/App.jsx`、`src/components/{CameraScanner,InventoryList,RegisterPanel}.jsx`

## ③ 誰が使えるようになるか(このアプリを例に)

| 人 | 直す前に困ったこと | 今回の直しで |
|---|---|---|
| **暗い画面で使う人**(夜の倉庫・スマホのダークモード) | 青いボタンの白文字が読みにくい | 読みやすくなる |
| **色の見え方が違う人**(色覚の特性) | 「選択中のタブ」が色の違いだけで分かりにくい | 太字でも分かる |
| **目が見えにくい人・読み上げを使う人** | 「プラス1」「プラス1」…で、どの商品か分からない。英語の発音で読まれる | 商品名つきで操作できる |
| **日差しの下・古い画面で使う人** | 非表示行の補助の文字が薄くて読めない | 読める濃さになる |

**今回は届いていない人:** キーボードだけで使う人・文字を大きくして使う人(#10・#11は未確認・未対応)。
