## 流れ

| 段階 | 内容 |
|---|---|
| お題 | 3つの案(買い物メモ・賞味期限チェッカー・一行日記)から、本人が賞味期限チェッカーを選択 |
| 仕様 | やること・やらないこと・受け入れ基準を先に決めた(ログイン・共有・通知はやらない) |

| 保存 | ブラウザの `localStorage`。壊れたデータ・保存失敗でも落ちない |
| 公開 | Vercel は二段階認証が通らず断念。Railway で公開URLまで到達 |
| 確認 | 公開URLを実ブラウザで操作: 登録・並び順・削除→元に戻す・再読み込み後も残る |
