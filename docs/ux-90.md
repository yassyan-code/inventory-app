## ② 一番迷う所を直す(#1)

**直し方の判断:** 自動+1の動きは変えず(店での速さを落とさない)、言葉と取り消しを直した(案A)。スキャンのあとに「入庫/出庫」を選ばせる案B は、間違いは減るが、1回ごとにタップが増えるので選ばなかった。

| | 直す前 | 直した後 |
|---|---|---|
| 結果の言い方 | 「現在の在庫数: 5（スキャンにより+1済み）」 | 「✅ 入庫を1件記録しました（在庫 4 → 5 個）」(大きく・緑) |
| 次にすること | 「数量を修正する場合はこちら」＋「＋1（入庫）」「−1（出庫）」 | 「同じ商品をもう1個入荷したら、もう一度スキャンしてください」 |
| 間違えたとき | 「−1（出庫）」を探して押す | 「↩ 間違えた（取り消す）」。**1回だけ**押せる。履歴には「入庫の取り消し」と残る |
| 取り消した後 | (表示が変わらず、何度でも押せる) | 「取り消しました。在庫は 4 個に戻りました」。ボタンは消える |
| 二重入庫 | ＋1を押すと起きる | ＋1ボタンをなくしたので起きない(増やすのは、再スキャンか在庫一覧の±) |
| 次へ進むボタン | 次のバーコードをスキャン | 次の商品をスキャン |

変更: `src/components/RegisterPanel.jsx`、`src/App.css`(`.scan-result__done`)。

## 一番の改善と気づき
