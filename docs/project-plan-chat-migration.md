## 📸 一番読めなかったリスク

**リスク#1（Denoランタイムとの非互換）。**

理由: 見積りをする時点では「移植」という言葉を使うと、つい「書いてあるロジックを別の場所に
コピーするだけ」という軽い作業に見えてしまう。しかし実際はNode.jsとDenoでランタイムそのものが
違い、`npm`パッケージの扱い・環境変数の取り方・HTTPハンドラの型まで別物になる可能性がある。
実際に手を動かして疎通確認するまでは、見積りの精度に自信を持てない部分だった。
だからこそ、これを「作業の一部」ではなく「最初に独立させて確認するタスク（#0）」として
切り出し、ここで問題が見つかった場合にバッファで吸収できる位置に置いた。
