## 良い点

AIの入口と出口の両方で検証している点が、とても安心できる。
- 入力: 文字数・カテゴリ数・型を、API呼び出しの前に拒否する（テストも「APIを呼ばないこと」まで確認している）
- 出力: JSON Schemaで縛ったうえで、返ってきた値を再度検証している（存在しない日付 `2026-02-30` も拒否）
- そのほか: `127.0.0.1` のみで待ち受け、Originを制限し、`store:false`、タイムアウト、同時実行1件+回数制限がある。エラーの詳細をログに出しすぎない配慮もある

「AIの出力は信用せず、検証してから使う」という方針が一貫していて、学ぶところが多かった。

## 改善提案（1つ）

18〜22行目の「ユーザーの明示指定でAIの答えを上書きする」処理について、次のように変えてはどうでしょうか。

優先度は `優先度は至急` のように**ラベル付き**のときだけ上書きしている。
一方カテゴリは、文章中にカテゴリ名が**含まれていれば**上書きされる。

たとえばカテゴリに「仕事」があり、入力が「仕事帰りに牛乳を買う」だと、AIが「買い物」と判断しても「仕事」に変わってしまうかもしれない。

優先度と同じく `カテゴリ:仕事` / `カテゴリは仕事` のようなラベル付きのときだけ上書きする形はどうでしょうか。
意図して今の動きにしているなら、その理由をコメントに残すだけでも十分だと思います。
今のテストにはこの上書きのケースがないので、次のテストを1件足すと安心です。
- 「ラベルなしでカテゴリ名を含む文」→ AIの判断が残る
- 「ラベル付き」→ 上書きされる
